# Predictive Modeling and Risk Scoring for Bank Customer Churn

## Project Overview
This project focuses on analyzing bank customer data and developing machine learning models to predict customer churn. It aims to identify customers who may leave the bank and support better customer retention decisions.

## Objectives
- Analyze customer characteristics and banking behavior.
- Identify patterns associated with customer churn.
- Build predictive models to estimate churn risk.
- Develop a risk-scoring approach to identify high-risk customers.
- Present insights through a user-friendly dashboard.

## Dataset
The project uses a European banking customer dataset containing customer demographics, account details, banking activity, and churn status. Personal identifiers will be excluded from model development and public project files.
