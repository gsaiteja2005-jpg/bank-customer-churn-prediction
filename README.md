# Predictive Modeling and Risk Scoring for Bank Customer Churn

## Project Overview
This project aims to predict bank customer churn using machine learning techniques. It analyzes customer information to identify customers who are likely to leave the bank and assigns risk scores to support customer retention strategies.

## Objectives
- Analyze bank customer data.
- Identify important factors influencing customer churn.
- Build machine learning models to predict customer churn.
- Generate customer-level churn probabilities and risk scores.
- Develop an interactive dashboard to display predictions and insights.

## Dataset
The dataset contains bank customer information, including:
- Credit Score
- Geography
- Gender
- Age
- Tenure
- Account Balance
- Number of Products
- Credit Card Status
- Active Membership
- Estimated Salary
- Churn Status (Exited)

Customer identifiers and surnames will not be used as model features.

## Expected Outcome
The project will provide a machine learning-based approach to identify customers at risk of leaving the bank and help banking organizations make data-driven customer retention decisions.
